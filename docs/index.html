Distances for diagrams
you already have.

Topp computes exact Bottleneck, W1,∞, and W2,2 distances between persistence diagrams. It is built for strict, repeated comparisons—not for constructing persistence itself.

Install Topp API reference

v0.1.0 public preview · Windows x64 wheels · CPython 3.10–3.14

01 / scope

A narrow tool for a specific job.

Use Topp when

  • Your pipeline already produces persistence diagrams.
  • Distance semantics must be exact for downstream thresholds.
  • One query is compared with many candidate diagrams.
  • You want NumPy as the only runtime dependency.

Use a broader TDA library when

  • You need filtrations or persistence computation.
  • You need arbitrary Wasserstein parameters.
  • You need approximate, GPU, Linux, or macOS support with a current validation guarantee.

Performance boundary. A controlled cross-library benchmark has not been published yet. Topp makes no end-to-end speed claim against GUDHI, Hera, or Persim.

02 / install

One runtime dependency.

Prebuilt wheels are currently available for Windows x64. NumPy is the only runtime dependency.

py -m pip install topp

Source builds may work elsewhere with CMake 3.24+ and a C++20 compiler. Linux and macOS are not covered by CI in v0.1.0.

03 / interface

Pairwise when you need one.
Prepared when you need many.

quickstart.pyPython
import numpy as np
import topp

x = np.array([[0.0, 1.0], [0.3, 0.8]])
y = np.array([[0.0, 1.1], [0.4, 0.9]])

d = topp.bottleneck_distance(x, y)
w = topp.wasserstein_distance(
    x, y, order=2, internal_p=2
)

query = topp.prepare_diagram(x)
batch = topp.bottleneck_distances(query, [y, x])
PreparedDiagram

Validates and copies a diagram once. The immutable result can be reused across calls and read concurrently.

out=np.empty(...)

Batch calls can fill caller-owned, contiguous float64 memory instead of allocating a new result.

bottleneck_within(...)

Answers an exact threshold question directly. Native distance calls release the Python GIL.

04 / semantics

Three supported metrics.
No silent substitutions.

Bottleneck

dB(X,Y)

Exact matching with L∞ point costs and an infinitely repeated diagonal.

Wasserstein

W1,∞(X,Y)

order=1 and internal_p=np.inf.

Wasserstein

W2,2(X,Y)

order=2 and internal_p=2.

Duplicates retain multiplicity. Finite diagonal points have zero persistence. Essential points match only the same essential type; incompatible multiplicities return inf.
